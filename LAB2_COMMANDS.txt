Lab 2 commands

1. Create local environment file from the safe example:
copy .env.example .env

2. Change values in `.env` before running containers:
POSTGRES_DB=fastapi_lab
POSTGRES_USER=<your_user>
POSTGRES_PASSWORD=<your_password>
JWT_SECRET_KEY=<your_secret_key>

3. Build and start FastAPI and PostgreSQL containers:
docker compose up --build

4. Start containers in detached mode:
docker compose up --build -d

5. Check running containers:
docker compose ps

FastAPI is available from the host at:
http://127.0.0.1:8001

PostgreSQL is available from the host at:
localhost:5433

6. Check installed Python libraries inside the FastAPI container:
docker compose exec api poetry show

7. Stop containers:
docker compose down
