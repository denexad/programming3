Lab 5 commands

1. Register user:
Make sure `.env` exists and contains local secrets before starting containers.
curl -X POST http://127.0.0.1:8001/auth/register -H "Content-Type: application/json" -d "{\"username\":\"newuser\",\"email\":\"newuser@example.com\",\"password\":\"secret123\"}"

2. Login and save cookie:
curl -i -c cookies.txt -X POST http://127.0.0.1:8001/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"admin123\"}"

3. Check current authenticated user:
curl -b cookies.txt http://127.0.0.1:8001/auth/me

4. Check authenticated profile endpoint:
curl -b cookies.txt http://127.0.0.1:8001/auth/me/profile

5. Check authenticated orders endpoint:
curl -b cookies.txt http://127.0.0.1:8001/orders/my

6. Logout:
curl -b cookies.txt -X POST http://127.0.0.1:8001/auth/logout
