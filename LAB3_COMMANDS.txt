Lab 3 commands

1. Start the project with Docker Compose:
docker compose up --build -d

2. Check the API documentation:
http://127.0.0.1:8001/docs

3. Get all users:
curl http://127.0.0.1:8001/users/

4. Create a user:
curl -X POST http://127.0.0.1:8001/users/ -H "Content-Type: application/json" -d "{\"username\":\"apiuser\",\"email\":\"apiuser@example.com\",\"password\":\"secret123\"}"

5. Get one user:
curl http://127.0.0.1:8001/users/3

6. Update a user:
curl -X PUT http://127.0.0.1:8001/users/3 -H "Content-Type: application/json" -d "{\"username\":\"apiuser2\",\"email\":\"apiuser2@example.com\"}"

7. Delete a user:
curl -X DELETE http://127.0.0.1:8001/users/3

8. Stop containers:
docker compose down
